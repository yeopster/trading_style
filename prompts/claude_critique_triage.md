# Prompt: triage an adversarial review (used by /triage)

Perplexity performed an adversarial review of the proposed experiment.
Review its criticisms. Do not defend the original idea automatically.

Classify every criticism as CRITICAL / IMPORTANT / MINOR / NOT APPLICABLE, with one line of
justification that refers to the actual code or data in this repo.

Redesign the experiment to address all CRITICAL and IMPORTANT issues before implementation.
Record the triage table and the redesign in the hypothesis file under "Adversarial review",
bump its version, and list any changes to code that the redesign requires.
